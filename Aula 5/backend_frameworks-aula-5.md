# Plano de Aula – Semana 5

**Disciplina:** Backend Frameworks  
**Curso:** Análise e Desenvolvimento de Sistemas  
**Tipo de Aula:** Teórica  
**Carga Horária:** 3 horas  

---

# Tema da Aula

Classificação de frameworks backend por linguagem (**Java, JavaScript, Python e PHP**), abordando diferentes categorias como:

- Frameworks de aplicação  
- Inversão de controle (IoC) e Injeção de dependência (DI)  
- Banco de dados (ORM)  
- Segurança  

A aula tem como objetivo desenvolver uma visão comparativa entre linguagens e seus ecossistemas.

---

# Objetivos da Aula

## Objetivo Geral

Compreender como os frameworks backend podem ser classificados dentro de diferentes linguagens, identificando suas responsabilidades e aplicações práticas.

---

## Objetivos Específicos

Ao final da aula, o estudante deverá ser capaz de:

* Classificar frameworks de acordo com sua finalidade  
* Diferenciar frameworks de aplicação, IoC/DI, ORM e segurança  
* Identificar frameworks mais utilizados em cada linguagem  
* Comparar abordagens entre Java, JavaScript, Python e PHP  
* Escolher frameworks adequados para diferentes cenários

# Conteúdo Programático

## 1. Introdução à Classificação de Frameworks (30 minutos)

Os frameworks podem ser classificados de acordo com o problema que resolvem dentro da aplicação.

---

### Principais critérios de classificação

* Tipo de aplicação (web, API, full stack)
* Responsabilidade dentro da arquitetura
* Nível de abstração
* Integração com outras camadas

---

### Categorias principais

#### Frameworks de Aplicação

Responsáveis por:

* Criar APIs REST
* Gerenciar requisições HTTP
* Definir rotas e endpoints

---

#### Frameworks de Inversão de Controle (IoC)

Responsáveis por:

* Controlar o ciclo de vida dos objetos
* Reduzir acoplamento entre componentes

---

#### Frameworks de Injeção de Dependência (DI)

Permitem:

* Injetar dependências automaticamente
* Facilitar testes e manutenção

---

#### Frameworks de Banco de Dados (ORM)

Responsáveis por:

* Mapear objetos para tabelas
* Abstrair queries SQL

---

#### Frameworks de Segurança

Responsáveis por:

* Autenticação
* Autorização
* Proteção contra vulnerabilidades

---
